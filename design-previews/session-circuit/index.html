현재 turn의 이벤트

연결 근거와 확인 범위

실시간 상태

IPC는 세션의 실행·입력 대기 상태를 제공합니다. 개별 작업 위치는 기록 이벤트와 함께 확인합니다. 이 시안은 실제 IPC에 연결하지 않습니다.

작업 연결

turn_id, call_id, native item ID와 parent_thread_id로 관계를 구성합니다. 시간순서는 작업 의존성으로 바꾸지 않습니다.

토큰 계측

기록된 input_tokens, cached_input_tokens, output_tokens, reasoning_output_tokens만 표시합니다. 캐시 입력은 입력의 일부이고 추론 출력은 출력의 일부입니다.

하위 세션

현재 turn의 위임·보고를 과거 하위 세션과 구분합니다. 선택한 하위 세션만 펼치며 현재 실행 상태를 확인하지 못하면 미확인으로 표시합니다.

숨겨진 자료

내부 reasoning과 암호화 payload는 표시하지 않습니다. 기록에 없는 관계나 토큰 사용량은 추정해 채우지 않습니다.

이 페이지의 이벤트·하위 세션·수치·결과는 디자인을 확인하기 위한 합성 자료입니다. 외부 요청, 프롬프트 전송, 명령 실행은 발생하지 않습니다.
