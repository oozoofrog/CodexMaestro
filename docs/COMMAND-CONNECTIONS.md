# Command 드래그와 연결 작업

> 이 문서는 아이템 겹치기 도입 전의 구현과 검증 기록입니다. 아래 Command 드래그·연결 모드 설명은 당시 동작이며 현재 조작 안내가 아닙니다. 현재 흐름은 [컨텍스트 토폴로지와 아이템 겹치기](CONTEXT-TOPOLOGY.md)를 확인하세요. 이전 로그와 검증 범위는 보존합니다.

2026-10-03 구현 기록. 현재 작업 설정은 참고, 전달, 검토, 직접 요청의 네 가지다. 실행 세션은 요청과 해당 세션에서 사용할 수 있는 스킬을 보고 필요한 스킬을 선택한다. Maestro는 스킬 목록을 조회하거나 특정 로컬 스킬 파일을 지정하지 않는다.

## 연결과 실제 작업 세션

기본 화면은 작업 흐름이다. 카드는 세션 제목과 상태를 표시하며 모델·추론·경로·ID는 선택한 세션의 `정보`에 접어서 보관한다. 범례와 조작 안내는 캔버스의 정보 버튼으로 연다. 실행 중인 세션과 저장 기록을 구분한다.

아이템을 선택한 뒤 Command 키를 누르고 해당 아이템에서 다른 아이템으로 드래그한다. 놓으면 먼저 연결을 저장하고 작업 설정을 연다. 설정창을 닫아도 선은 남는다. 카드의 연결 아이콘을 누른 뒤 대상을 클릭해도 같은 작업창을 연다. 설정은 양쪽 상세 패널의 `요청`과 연결 관리자에서 다시 열 수 있다. 툴바의 `연결 드래그 모드`를 켜면 Command 키 없이 같은 드래그 경로를 사용한다. 일반 세션 드래그는 노드 위치를 바꾼다.

세션→세션, 프로젝트→프로젝트, 세션→프로젝트, 프로젝트→세션을 모두 지원한다. 관계의 출발과 도착은 선의 방향이다. 실제 실행 위치는 별도로 선택한다.

| 기능 | 기본 실행 위치 | 참고 자료 |
|---|---|---|
| 참고 | 출발 노드 | 도착 노드 |
| 전달 | 도착 노드 | 출발 노드 |
| 검토 | 도착 노드 | 출발 노드 |
| 직접 요청 | 출발 노드 | 도착 노드 |

모든 기능에서 출발과 도착 중 실행 위치를 바꿀 수 있다. 예를 들어 `개발 세션 A → 조사 세션 B`에서 참고 기능의 기본값은 A가 B의 자료를 참고하는 동작이다. 전달 기능의 기본값은 B가 A의 자료와 요청을 이어받는 동작이다. 화면은 작업할 위치, 참고할 대상, 실제 실행 세션을 함께 표시한다.

실행 위치가 프로젝트이면 사용자가 그 프로젝트에 속한 세션 하나를 지정한다. 지정 전에는 설정을 저장할 수 있지만 초안은 준비할 수 없다. 다른 프로젝트의 세션, 이동하거나 삭제된 세션은 실행 대상으로 승인하지 않는다. 프로젝트 전체에 자동으로 전송하지 않는다.

## 프롬프트와 스킬

참고·전달·검토에는 추가 작업 지시를 입력할 수 있다. 직접 요청에는 수행할 프롬프트를 입력해야 한다. 전체 생성 내용은 기본으로 접힌 `보낼 내용`에서 확인한다. 생성한 초안의 마지막에는 다음 지시가 포함된다.

> 이 세션에서 사용할 수 있는 스킬 중 요청에 적합한 스킬이 있으면 직접 선택해서 사용하세요. 적합한 스킬이 없으면 일반 작업 방식으로 진행하세요. 요청을 수행하는 데 반드시 필요한 스킬을 사용할 수 없으면 누락된 조건을 명시하세요.

이 지시는 수신 세션에 선택을 맡긴다. Maestro가 스킬 활성 상태나 모델의 실제 스킬 호출을 보장하지는 않는다. 사용자가 프롬프트에 특정 스킬 요청을 직접 입력하는 것은 가능하다.

세션 참고에는 최근 저장된 assistant 응답을 최대 16,000자로 포함한다. 저장 응답이 없으면 카탈로그의 세션 요약을 사용하며 그 범위를 표시한다. 프로젝트 참고에는 이름, ID, 경로를 포함한다. 프로젝트 파일이나 구성원 대화를 자동으로 읽지 않는다. 받는 세션은 요청에 필요한 파일을 직접 확인하며 접근할 수 없으면 누락된 근거를 표시한다.

## 준비와 전송

`저장`은 연결의 작업 설정만 저장한다. `초안 준비`는 화면에 표시한 내용을 그대로 실제 실행 세션의 입력창에 넣는다. 담당 세션을 선택해도 전체 프로젝트 흐름은 유지한다. 준비한 뒤 사용자가 내용을 편집하고 `전송`해야 Codex가 실행한다. 연결 생성, 설정 저장, 초안 준비는 메시지를 전송하지 않는다.

다른 내용의 기존 초안이 있으면 준비를 멈추며 기존 초안을 유지한다. 초안 준비 전에 현재 연결과 두 대상, 실제 세션의 현재 소속을 다시 확인한다. 설정 변경 중 이전 비동기 미리보기가 완료되어도 새 설정에 사용하지 않는다. 설정과 초안을 함께 저장하다 실패하면 이전 작업공간을 복원한다.

## 저장과 호환성

연결별 설정은 UUID로 결합하여 작업공간 버전 3에 저장한다. 버전 1과 2의 기존 연결·위치·초안을 계속 읽는다. 연결을 편집하면 설정을 유지하며 실행 쪽 노드가 바뀌면 담당 세션을 비운다. 연결을 삭제하면 해당 설정도 삭제한다.

이전 선택기가 기록한 `skill`, `skillName`, `skillPath`는 읽기 호환성을 위해 해석한다. 설정을 열거나 저장하거나 초안을 만들 때 `직접 요청`으로 변환하고 스킬 이름·경로 결합을 해제한다. 비어 있지 않은 기존 프롬프트, 실행 방향, 담당 세션은 유지한다. 빈 이전 스킬 요청에는 `참고 자료를 바탕으로 작업을 진행하세요.`를 사용한다. 파일이 없거나 스킬이 제거됐어도 설정을 열 수 있다. 기존에 준비한 세션 초안은 자동으로 바꾸지 않는다.

## 검증 범위

현재 검증 결과는 [VALIDATION.md](VALIDATION.md), 독립 Astra 검토는 [COMMAND-CONNECTIONS-REVIEW.md](COMMAND-CONNECTIONS-REVIEW.md)에 기록한다. 테스트와 네이티브 데모, 실제 Codex 읽기 전용 연결을 구분한다.

Command 키가 최초 인식 시 눌려 있거나 접근성 연결 모드가 켜져 있으면 드래그 모드를 고정한다. CUA의 native drag API에는 modifier 유지 기능이 없어 물리 Command 키를 누른 전체 동작은 아직 런타임에서 확인하지 않았다. 접근성 모드의 네이티브 드래그는 같은 좌표·드롭·설정 경로를 사용하며 이 경로는 실제 앱에서 검증한다.

긴 같은 행의 연결은 카드 상단에서 우회하여 기본 배치의 가운데 카드를 피한다. 임의로 배치한 모든 노드에 대한 장애물 회피를 보장하지 않는다. 실제 업무 세션으로 요청을 보내 모델 응답과 스킬 사용을 관찰하는 E2E는 아직 수행하지 않았다.
