# 디자인 적용 및 최종 검증

검증일: 2026-10-03 (Asia/Seoul).

## 기준과 적용 범위

사용자가 지정한 채팅 `01a1010f-d0da-79e1-98fb-85e938299200`의 최신 시안은 `design-previews/maestro-topology.html`이다. 이 파일의 색상, 패널 구성, 카드, 선택 표시, 연결선과 프로젝트 상세를 SwiftUI 앱에 적용했다. 원본 시안은 변경하지 않았다.

기본 창은 1480 × 920pt이다. macOS 기본 툴바, 크기를 조절하는 분할 패널, 스크롤·확대 가능한 캔버스, 네이티브 연결 편집기를 사용한다. 사이드바와 상세 패널은 툴바에서 표시를 전환한다. 화면 모드는 시스템 설정, 밝게, 어둡게 중에서 선택한다. 검증 후 시스템 설정으로 복원했다.

세션 카드는 240 × 112pt, 프로젝트 카드는 240 × 58pt이다. 기본 열 간격은 285pt이며 기본 확대율은 85%이다. 선택 노드는 파란 테두리와 배경을 사용한다. 소속선은 중립색 실선, 사용자가 만든 관계는 목적별 색상과 방향 화살표, 부모 관계는 점선으로 표시한다. 연결 목적 라벨은 카드와 다른 라벨을 피한다. 이동한 라벨은 가는 안내선으로 해당 곡선에 연결한다.

캔버스의 프로젝트 노드 선택은 상세 패널만 변경한다. 사이드바 프로젝트 선택은 표시 범위를 해당 프로젝트로 제한한다. 프로젝트 상세는 세션·실행·관계 수와 들어오는·나가는 연결을 표시한다. 프로젝트 없는 세션도 같은 소속 판정으로 집계한다.

리더는 실제 앱을 CUA로 조작했다. Astra는 최종 소스, 회귀 결과, 저장한 네 장의 최종 화면을 독립 확인했다. 발견한 결함은 프로젝트 없는 세션의 잘못된 집계와 관계 라벨의 카드 겹침이었다. 두 결함과 라벨 검색 경계의 오류를 수정하고 검증했다.

앱은 일반 Codex 연결 모드로 실행해 두었다. 마지막 화면에서 로컬 카탈로그606개, 연결된 세션11개, 선택한 이 개발 세션의 실행 상태, 모델, 추론 수준, 저장된 메시지30개를 확인했다. `evidence/design-live-final.png`은 이 실제 데이터 화면이다. 조회 수는 시점에 따라 바뀐다.

## 보존한 동작과 검증 한계

기존 연결 검증, 저장 실패 복원, 초안 보존, 전송 상태, 대화 선택 경합 처리, IPC 쓰기 기한과 스레드 설정 상속은 유지한다. 데모 검증은 실제 업무 세션으로 메시지를 보내지 않으며 실제 작업공간을 저장하지 않는다. 검증용 전체 카탈로그는 읽기 전용 스냅샷이다.

HTML의 연결 라벨은 선택 버튼이다. 네이티브 앱의 라벨은 관찰용 Canvas 텍스트이며 관계 이동과 편집은 상세 패널과 연결 관리자에서 수행한다. 다른 카드를 드래그하면 정적인 라벨을 일시적으로 가릴 수 있다. 드롭 후 배치를 다시 계산한다. 240pt 이내에서 빈자리를 찾지 못하면 해당 라벨을 생략하고 화살표와 상세 관계를 유지한다.

드래그 카운터는 포인터 이동 중 전체 배치 계산이 없다는 근거다. FPS나 체감 부드러움의 전후 비교는 측정하지 않았다. 실제 프롬프트 전송부터 모델 응답 완료까지의 E2E, 전체 VoiceOver 탐색, 공증과 외부 배포는 검증하지 않았다.
